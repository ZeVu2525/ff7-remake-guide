# 自分で追加する地図

このフォルダには、自分で用意した地図画像だけを置きます。攻略サイトの画像はダウンロードして置かないでください。権利は掲載元にあります。いまの章地図は、これまでどおり掲載元のURLを参照します。

1. カード編集で画像ファイルを選ぶか、画像のURLを入れる。
2. 「ルートJSを書き出す」を押す。新しい画像はファイルとしてダウンロードされ、`maps.js` もダウンロードされます。
3. 画像は GitHub の Add file → Upload files で、この `maps/` に上げる。
4. ダウンロードした `maps.js` は、リポジトリの `data/maps.js` と置き換える。
5. 書き出した `data-route.js` は `data/route.js` と置き換える。依頼の地図を変えたときは、台帳の書き出しも置き換える。

同じ中身の画像は、同じファイル名になります。画面はそのファイルを1回だけ読みます。
